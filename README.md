# StarLine

Desktop-first, offline-by-default novel planner and writer workstation: guided Snowflake-method
planning from one sentence to a scene-by-scene outline, with characters, relationships, lore,
timeline and notes cross-linked — all in a single file the user owns (`*.starline`, a SQLite
database).

- `SPECIFICATION.md` — the source of truth (v1.0.0, implementation-ready).
- `DECISIONS.md` — owner decisions and pre-build audit resolutions on top of the spec.
- `AGENTS.md` — build gates and conventions for contributors and agents.

**Status:** M0 (Foundation) in progress. Nothing user-facing is complete yet.
